# Autophobia.me

This repo is the public website at https://autophobia.me/. The game is not in this repo.

The page is a work in progress. The home page links to the mini-game hub (Snake, Tetris, Breakout, Memory, Minesweeper).

## For an AI working on this repo

Read `AGENTS.md` before editing.

This repo is only the live website. The game lives in the private repo `EdgeCCTV/autophobia`. Do not copy the game, `src/`, `assets/`, or audio into this repo.

The source copy of these files is the `docs/` folder in `EdgeCCTV/autophobia`. When the website changes, update both places:

1. `docs/` in `EdgeCCTV/autophobia`
2. The root of this repo

Then push both. Pushing only the private repo does not change https://autophobia.me/.
